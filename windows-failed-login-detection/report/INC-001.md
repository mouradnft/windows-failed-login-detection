# INC-001 – Repeated Failed Logons

## Summary
Multiple failed login attempts were generated against the local `labuser` account in a controlled Windows lab environment.

## Evidence
- Event ID: 4625
- Account: `labuser`
- Host: `DESKTOP-HCNQQ8M`
- Failure reason: Unknown user name or bad password
- Logon type: 2
- Source address: 127.0.0.1

## Analysis
The Windows Security log recorded repeated failed interactive logon attempts against the `labuser` account. Event ID 4625 confirmed that authentication failed because an incorrect password was entered.

Because the source address was `127.0.0.1`, the login attempts originated from the same local Windows system rather than from a remote host.

## Containment / Response
If this activity were unexpected in a real environment, I would review the number and frequency of failures, confirm whether the user recognized the attempts, inspect related authentication events, and determine whether the account should be temporarily locked or monitored.

## Remediation
- Monitor repeated failed logins.
- Use an appropriate account lockout policy.
- Require strong passwords.
- Investigate unusual login patterns or source addresses.

## Conclusion
The activity was intentionally generated as part of a controlled cybersecurity lab. The exercise demonstrated how failed Windows logins can be identified using Event Viewer and investigated using PowerShell.
